# Siddhartha Suva Trade Link

Next.js 14 (App Router) + Tailwind + Framer Motion + react-three-fiber + GSAP + Lenis.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Replace later
- Team portraits: drop real photos into `public/team/` and update the `photo` paths in `app/about/page.tsx`
  (placeholders are `ujjwal.svg`, `sindhu.svg`, `utkrista.svg`, `aryan.svg`).
- Product images live in `public/products/` (cut out of your reference PDF). Swap in higher-resolution
  bucket shots with the same file names, or edit `lib/products.ts`.
- Video: `public/videos/sidhhartha.mp4` (cropped from your screen recording) and `poster.jpg`.
- WhatsApp number and message text: `lib/whatsapp.ts`.
